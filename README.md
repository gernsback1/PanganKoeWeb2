# PanganKoe Web

PanganKoe is a simple nutrition and meal-planning landing page that helps users plan daily and weekly meals based on budget and health needs. 
This repository contains a static front-end prototype (HTML, CSS, and a small placeholder JS file).

---

### Description — English
PanganKoe is a lightweight front-end prototype designed to:
- Help users plan meals according to budget
- Improve nutrition by suggesting balanced meal choices
- Provide a friendly landing page and a simple registration page

### Deskripsi — Bahasa Indonesia
PanganKoe adalah prototipe front-end ringan yang dirancang untuk:
- Membantu pengguna merencanakan menu sesuai anggaran
- Meningkatkan pola makan dengan pilihan makanan bergizi
- Menyediakan halaman landing yang ramah dan halaman pendaftaran sederhana

---

## Features / Fitur
- Static landing page (home.html) with green-themed styling
- Registration page (register.html)
- Hero section, CTA button, and feature cards
- Easy to open and run locally (no build tools)
